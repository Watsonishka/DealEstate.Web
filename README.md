# 🏢 DealEstate - платформа для продажи недвижимости

Полнофункциональное веб-приложение для просмотра, подбора, сравнения и оформления заявок на покупку объектов недвижимости (квартиры, загородные дома) с развитой панелью администратора, ролевой моделью доступа и хранением данных в PostgreSQL.

---

## 🏗 Архитектура решения

Решение разделено на независимые слои в соответствии с принципами чистой архитектуры:

- **OnlineShop.DB** — слой доступа к данным:
  - Сущности Entity Framework Core (`Product`, `Apartment`, `House`, `Bid`, `Order`, `Favorite`, `Comparison`).
  - Расширенная модель пользователя (`User`) и контексты БД.
  - Реализация репозиториев / хранилищ (`Storages`) для абстракции работы с базой данных.
    
<img width="292" height="164" alt="image" src="https://github.com/user-attachments/assets/afcea528-5fa3-4222-85e7-8731ac3157b1" />
    
- **OnlineShopWebApp** — презентационный веб-слой (ASP.NET Core MVC):
  - Контроллеры пользовательской и административной зон.
  - ViewModels для безопасного отображения и передачи данных.
  - Статический `Mapper` для строгой проекции моделей представления и сущностей БД.
  - Razor-представления со стилизованным темным UI.

## 🚀 Основные возможности

### 🏠 Каталог и карточки объектов недвижимости
- Разделение объектов по категориям: **Квартиры** и **Дома/Коттеджи**.
  
В основе каталога лежит объектно-ориентированная архитектура:
* **`Product` (абстрактный базовый класс)** — инкапсулирует общие характеристики всех объектов недвижимости (название, застройщик, город, цена, общая площадь, этажность, описание, превью-изображение, категория).
* **`Apartment` (наследник)** — расширяет базовую модель специфичными параметрами: номер этажа (`Floor`), высота потолков (`CeilingHeight`), класс жилья (`Class` — комфорт, бизнес, элит) и наличие балкона (`HasBalcony`).

## 🛠 Стек технологий

- **Платформа:** .NET 10 / C#
- **Веб-фреймворк:** ASP.NET Core MVC
- **Аутентификация & Авторизация:** ASP.NET Core Identity
- **ORM & База данных:** Entity Framework Core, PostgreSQL
- **Frontend:** HTML5, CSS, JavaScript, Bootstrap

---

## 💡 Особенности реализации

- **Разделение бизнес-логики и маппинга:** Статический маппер отвечает только за трансформацию типов данных, в то время как бизнес-правила (простановка статусов, даты создания, аутентификационные флаги) инкапсулированы в сервисах и контроллерах.
- **Иерархия моделей (TPH):** Использование полиморфизма EF Core для хранения различных типов недвижимости (`Apartment`, `House`) на базе единой сущности `Product`.
- **Кастомные элементы интерфейса:** Кастомизированные файловые инпуты и темная UI-тема без стандартных браузерных артефактов.
- **Безопасная работа с ролями:** Разграничение системных неизменяемых ролей и пользовательских ролей через флаг `IsCustom`.
